# Ivana Molina - Bienes Raíces

Aplicación web inmobiliaria moderna e inmersiva con animaciones interactivas:
- **Stacked Unfold Cards**: Despliegue 3D progresivo vinculado al scroll.
- **Capsule Reveal Mask**: Animación de entrada en cápsula para el listado de propiedades en 2 columnas.
- **Transiciones fluidas** con GSAP y ScrollTrigger.
- Diseño responsivo y moderno.
